# 即刻出走 · 旅行助手

访问：https://dannybinbin.github.io/weekend-away/

手机和电脑均可使用。旅行偏好与计划保存在当前浏览器，可在「本机数据」导出备份。

## 实时酒店

「实时酒店」支持按目的地、入住离店日期、成人数、星级和每晚房费预算查询 RollingGo 酒店报价。结果显示整段住宿总价、每晚均价、查询时间，并提供供应商预订页链接。

实时查询由独立阿里云后端处理，供应商密钥只在服务器端保存。GitHub Pages 仓库仅存放静态发布产物，不包含密钥或用户数据。

## 体验范围

发现页交通价格与行程草案仍为示例。RollingGo 当前公布的机票接口实测返回 404，实时机票暂未开放；也尚未提供真实登录、云端同步、订单上传、定时抓价或飞书/钉钉推送。

报价和库存会变化，以预订页最终房型、税费、入住人数及退改政策为准。酒店星级由供应商提供，不代表全网最低价。
