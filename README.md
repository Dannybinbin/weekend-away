# 即刻出走 · 旅行助手

GitHub Pages 浏览器体验版。此仓库只包含发布用静态网页及图片，不包含后端服务、账号数据或密钥。

- 浏览示例旅行机会，按预算、时间和交通方式筛选。
- 偏好、旅行计划和模板行程草案保存在当前浏览器，可导出 JSON 备份。
- 暂不提供真实登录、云端同步、订单上传、机器人绑定、实时报价或自动推送。
- 清除浏览器数据、换设备或使用无痕窗口不会自动恢复计划。

图片作者、来源和许可详见网页底部「查看署名」。

更新方式：在原项目运行 `npm run build:pages`，将 `dist-pages/` 中的静态文件发布到本仓库；GitHub Pages 使用 main 分支根目录。
